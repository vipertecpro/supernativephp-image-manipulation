# Screenshots

Drop your captures here with these exact filenames — the main README references them:

| File | What to capture |
|---|---|
| `home.png`    | The home screen (the five example cards) |
| `studio.png`  | Image Studio — the full editor (crop + presets) |
| `profile.png` | Profile Photo — the circular avatar preview or its editor |

Optional (nice to have):

| File | What to capture |
|---|---|
| `cover.png`  | Cover Photo example |
| `adjust.png` | Adjust example |
| `filter.png` | Filter example |
| `demo.gif`   | A short screen recording of a full pick → edit → done flow |

**How to capture**
- **iOS Simulator:** `⌘S` for a screenshot, or `File → New Screen Recording`.
- **Android Emulator:** the camera/record icons in the emulator toolbar.
- Recording → GIF: `ffmpeg -i demo.mov -vf "fps=15,scale=320:-1" demo.gif`
